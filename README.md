# Mailwave

מערכת לניהול רשימות תפוצה, רצפי מיילים אוטומטיים, מיילים מתוזמנים ונתוני אמת
(נשלחו, נפתחו, קליקים, הסרות), שנבנתה בשביל lital oss.

## מה יש בפנים

- 6 רשימות תפוצה: `config/lists.ts`
- רצף של 20 מיילים לרשימה הראשית: `config/emails/main-list.ts`
- השם, הצבעים והתמונה: `config/brand.ts` ו `public/`
- ההצעות והקישורים שבסוף כל מייל: `config/offers.ts`
- מנוע השליחה (Resend) ומסד הנתונים (Supabase): `lib/` ו `supabase/schema.sql`

## הפעלה במחשב

צריך Node.js בגרסה 20 ומעלה (nodejs.org, הכפתור LTS).

```
npm install
npm run dev
```

ואז לפתוח בדפדפן: http://localhost:3012/mail
אם הפורט 3012 תפוס, אפשר להפעיל על פורט אחר: `npx next dev -H localhost -p 3013`

בלי חיבור ל Supabase ול Resend המערכת עובדת במצב תצוגה: רואים את כל המסכים, את הרשימות
ואת 20 המיילים, ושום מייל לא נשלח.

## הקמה מלאה (כשרוצים שהמיילים ייצאו באמת)

1. **הפרטים שלך:** להחליף את הקישורים הזמניים (example.com) ב `config/offers.ts` בקישורים האמיתיים
   של האתגר והמדריכים, ולמלא ב `config/brand.ts` מאיזו כתובת יוצאים המיילים ואת המייל שלך לבדיקות.
2. **Supabase** (חינם): לפתוח פרויקט חדש, להריץ ב SQL Editor את כל `supabase/schema.sql`,
   ולהעתיק את `Project URL` ואת מפתח ה `service_role` לקובץ `.env.local` (לפי `.env.example`).
3. **Resend** (חינם עד 3,000 מיילים בחודש): לאמת את הדומיין שלך, להפעיל Open tracking ו Click tracking
   ולהוסיף את רשומת ה CNAME של ה tracking (בלעדיה העמודות "נפתחו" ו"קישורים שנלחצו" נשארות 0),
   וליצור מפתח API.
4. **העלאה לאוויר ב Vercel** (חינם): להעלות את הפרויקט, ולהגדיר את כל המשתנים מ `.env.example`.
   `ADMIN_PASSWORD` היא הסיסמה לכניסה שלך למערכת: כדאי סיסמה ארוכה ואקראית, ולשמור אותה במקום בטוח.
   אחר כך להוסיף ב Resend Webhook לכתובת `/api/webhooks/resend` של האתר.
   בתוכנית החינמית של Vercel השליחה האוטומטית רצה פעם ביום. כדי שמיילים מתוזמנים ייצאו בשעה המדויקת
   אפשר להגדיר ב cron-job.org (חינם) קריאה כל 15 דקות ל `/api/cron/sequences` ול `/api/cron/broadcasts`
   עם `?secret=` והערך של `CRON_SECRET`.
5. **בדיקה:** לשלוח לעצמך מייל בדיקה מכל מייל (הכפתור "שלח מייל בדיקה"), להירשם בעצמך דרך הטופס,
   ולבדוק שהקישור "להסרה מהרשימה" עובד. רק אחרי זה לחבר את הטופס האמיתי באתר.
6. **אפליקציה ב Mac:** לפתוח את כתובת המערכת ב Safari, ובתפריט: קובץ ← הוסף ל Dock.

## חיבור טופס באתר שלך

כל טופס יכול לשלוח ל `POST <כתובת המערכת>/api/subscribe` עם השדות `email`, `list` (המזהה מ `config/lists.ts`),
`name`, `phone`, ו `redirect` (לאן להעביר אחרי ההרשמה):

```html
<form action="https://YOUR-MAILWAVE-SITE/api/subscribe" method="POST">
  <input type="hidden" name="list" value="lm_ingredients">
  <input type="hidden" name="redirect" value="https://litalosshealthcoach.com/thank-you">
  <input name="name" placeholder="שם">
  <input name="email" type="email" required placeholder="מייל">
  <button>שלחו לי</button>
</form>
```

## שימוש יומיומי

- **מייל מתוזמן לרשימה:** להוסיף אותו ב `config/broadcasts.ts`, לשלוח לעצמך בדיקה, ורק אז להעלות.
- **מייל נוסף ברצף:** ב `config/emails/main-list.ts`, תמיד בסוף הרצף.
- **רשימה חדשה:** ב `config/lists.ts`.
- **נתונים:** הכל במסך. כל מספר בטבלה לחיץ ומראה את האנשים עצמם.

## הסגנון של המיילים

ככה נכתבו 20 המיילים שבמערכת, וככה כדאי להמשיך:
1. לשון נקבה, כמו חברה שכותבת לחברה קרובה.
2. ערך פרקטי שאפשר לעשות כבר היום, ומדי פעם סיפור אמיתי שלך.
3. בערך 150 עד 175 מילים, שורות קצרות של 3 עד 7 מילים.
4. נושא קצר ומסקרן, ולא לסיים כל נושא ב "...".
5. קישור באמצע או בסוף ועוד אחד בנ.ב. קישור בתחילת המייל רק מדי פעם.
6. בלי מקפים ובלי מילים קשות.
7. לא לכתוב שזה חלק מסדרה ("המייל הקודם", "המייל האחרון").

## כללי בטיחות

1. אף מייל לא יוצא לרשימה לפני שבדקת אותו במייל בדיקה לעצמך.
2. מפתחות וסיסמאות רק ב `.env.local` ובהגדרות של Vercel, אף פעם לא בתוך הקוד.
3. לא לשנות `id` של רשימה, רצף או מייל אחרי שהתחילו לצאת מיילים (זה יגרום לשליחה חוזרת).
4. לא לשנות את `CRON_SECRET` אחרי שיצאו מיילים (קישורי ההסרה הישנים יפסיקו לעבוד).
5. כל מייל יוצא עם קישור הסרה. התבנית מוסיפה אותו לבד.

## מבנה הקוד

- `app/components/MailChannel.tsx`: המסך עצמו (תפריט, תזמון, אנליטיקה, רשימות).
- `lib/engine.ts`: השליחה. כל מייל נרשם בטבלת `sends` לפני שהוא יוצא, כדי שאף אחת לא תקבל אותו פעמיים.
- `lib/data.ts`: הנתונים שבמסך. בלי Supabase הכל מוצג באפס.
- `app/api/subscribe`: הרשמה, ומייל ראשון מיד. `app/api/unsubscribe`: הסרה עם קישור חתום.
- `app/api/webhooks/resend`: אירועים מ Resend (נמסר, נפתח, נלחץ). `app/api/cron/*`: שליחה מתוזמנת.
- `middleware.ts`: כל המערכת נעולה בסיסמה (`ADMIN_PASSWORD`).
